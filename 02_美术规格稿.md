# 《众包站长模拟器》美术规格稿 v1.0

> 出图方式:全部由 GPT 生图。本稿提供统一风格约束、资产清单、尺寸命名规范和每张图的英文 prompt 模板。**所有 prompt 末尾都要拼接「全局风格串」**,保证整套图风格一致。

---

## 一、全局风格

- **基调**:写实偏插画的暗色都市风,冷灰蓝底色 + 外卖黄(#FFC300)作为唯一高饱和撞色,呼应"平台黄"的讽刺意味。
- **光线**:阴天/夜晚/雨天为主,低饱和,轻微颗粒感。
- **禁忌**:不出现真实平台logo、真实人物;事故类插图用**事后场景或剪影**表现,不画血腥细节。

**全局风格串(拼在每条prompt末尾)**:
```
, dark muted urban color palette with cold gray-blue tones and a single saturated delivery-yellow accent (#FFC300), semi-realistic digital illustration, cinematic overcast lighting, slight film grain, satirical somber mood, no text, no logos
```

## 二、文件规范

| 项 | 规范 |
|---|---|
| 格式 | 立绘/图标/按钮:PNG透明底;背景/插图:JPG或PNG |
| 命名 | 全小写下划线:`char_boss_smug.png`、`bg_station_day.jpg` |
| 目录 | `assets/char/`、`assets/bg/`、`assets/event/`、`assets/ui/` |
| 立绘 | 1024×1536(竖构图,半身或七分身,透明底) |
| 背景 | 1920×1080 |
| 事件插图 | 1280×720 |
| 按钮 | 512×160(常态/按下 两态即可,悬停用CSS变亮) |
| 图标 | 256×256 透明底 |

> GPT出图若带底色,让它"isolated on plain white background",再抠图;或直接要求 transparent background。
